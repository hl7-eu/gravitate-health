## Semantic Styling

The focusing operations can also add information, which requires a organized way of showing information of the same category.

The current categories are:

1. Warning
1. Information
1. Suggestion

### Suggestion

**Advice:**Consider using structured data models like FHIR to ensure interoperability.

### Warning

**Warning:**Do not modify the core configuration file directly in production environments.

### Information

**Information:**The data will be updated every 24 hours from the source system.
